A program that prints the funniest one-line excuse an AI agent can offer after failing a task.

## Run it

```sh
python3 main.py
```

## About this entry

`main.py` prints exactly one line of 111 characters and nothing else:

> The task is done. Unfortunately 'done' and 'correct' had a scheduling
> conflict, and only one of them showed up.

It asserts the line stays a single line of at most 200 characters, so two
runs always print identical output.
